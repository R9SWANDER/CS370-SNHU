# CS370-SNHU

In CS370, I learned about the current and emerging trends of the Computer Science field. The biggest trend is Artificial Intelligence, or AI, as well as new ethical concerns arising as a result of AI's potential capabilities. 

In the course we worked with various Reinforcement Learning models, to acheieve digital solutions to complex problems using AI. We solved balancing a pole on a cart, and a maze, with AI. The baseline declarations and helper functions were provided in each assignment, however, I had to implement the driving loop of the learning model and correct correlate all the helper functions. I also had to test the model to make sure it functioned correctly, and make adjustments accordingly to values such as the Learning Rate and Epoch Size, to ensure the model was operating efficiently.

In the context of the Computer Science field, this course taught me how Scientists approach digital problems, and how they build solutions. There are often similar frameworks which can be applied to very different problems, a Computer Scientist's job is to know their options, choose the best fit for the ideal solution, and modify the framework as needed to fit the specific scenario. This approach was used in both the cartpole and maze problems to find and implement a solution. Furthermore, A Computer Scientist must be aware of the ethical implications of the end use of the software. As a constantly changing field, Computer Science is succeptible to ethical dilemmas, and a Computer Scientist must be able to navigate and advise others on the ethical implications of proposed software. It is our responcibility to educate our partners in the field on these ethical issues, and how to create software which does not breach them.
